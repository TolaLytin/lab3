# Отчет по лабораторной работе №3

## 1. Данные и подготовка
- **Student_Performance.csv**: Признак `Extracurricular Activities` закодирован как 1 (Yes) и 0 (No). Все признаки масштабированы с помощью `StandardScaler` (для улучшения сходимости градиентного спуска).
- **german.csv**: Целевая переменная `Creditability` взята из первого столбца. Категориальные признаки закодированы с помощью One-Hot Encoding, числовые — стандартизированы.
- Данные разбиты на train/test в пропорции 80/20.

## 2. Гипотезы и эксперименты
- Скорость обучения: 0.05 для регрессии, 0.1 для классификации.
- Количество эпох: 800 для регрессии, 1000 для классификации.
- В собственной реализации использовался пакетный градиентный спуск.

## 3. Метрики
Результаты записаны в `experiment_results.json`. 
- Собственная логистическая регрессия показала ROC-AUC около 0.75.
- Sklearn Logistic Regression показала схожие результаты, что подтверждает корректность реализации.

## 4. Выводы
Собственная модель логистической регрессии работает на уровне готовых решений. KNN показывает хорошие результаты, но чувствителен к масштабу, а Decision Tree склонен к переобучению.

## 5. Воспроизводимость
Все результаты можно воспроизвести, запустив `linear_models.py` с фиксированным `random_state=42` при разбиении данных.
